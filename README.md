# Iris Flower Classification

A Machine Learning project that classifies Iris flowers into different species using the K-Nearest Neighbors (KNN) algorithm.

## Features
- Data Preprocessing
- Data Visualization
- Model Training using KNN
- Accuracy Evaluation
- Confusion Matrix Visualization

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## Dataset
The dataset contains:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width
- Species

## Algorithm
K-Nearest Neighbors (KNN)

## Output
The model predicts the species of Iris flowers:
- Setosa
- Versicolor
- Virginica

## Run the Project

```bash
python iris_classification.py
